# Tevet conTest grader invariance — findings

**Date:** 2026-08-03 · **Branch:** `olmo-self-scoring`
**Question:** is D = C·a_n a property of the text being scored or of the grader
θ scoring it, on the crowdsourced Tevet conTest datasets (human-labeled
diversity, three task families)? Companion to the OLMo self-scoring matrix
(`results/rlhf_experiment/matrix/FINDINGS.md`), which asks the same question on
model-generated text.

## Design

Four graders spanning three model families and more than two orders of
magnitude of scale (124M to 30B) score the same conTest response sets with
identical settings (completion format, 50 permutations): Qwen2.5-3B (`qwen25_completion_v3`, the paper's
published run), Qwen3-30B-A3B (`qwen3_30b_a3b`, prior run), Llama-3.1-8B base
(`llama8b_completion`, new), and GPT-2 124M (`gpt2_completion`, new). Per-sample
D = C·a_n (per byte) is derived from the full per-permutation sidecars with the
same mean-of-ratios aggregation as `analyze_c_ainf.py`. decTest is excluded:
its sign flips are known temperature-scaling artifacts, not an invariance
testbed.

Three views per conTest file, all on the common sample subset:

1. **Spearman ρ between D and the human diversity label, per grader** — does
   every grader see the human-grounded signal?
2. **Pairwise Spearman between graders' per-sample D** — do different families
   rank the same texts the same way?
3. **Two-way variance decomposition of the item × grader D matrix** — raw
   (grader share includes each model's absolute bits/byte scale offset) and
   within-grader z-scored (scale/location removed; item share vs
   grader-disagreement interaction).

## Reproduce

```bash
# score conTest with a new grader at v3-comparable settings (example: Llama-8B)
CUDA_VISIBLE_DEVICES=0 uv run python scripts/compute_icl_metrics_for_tevet.py \
  --base-model unsloth/Meta-Llama-3.1-8B --run-tag llama8b_completion \
  --format-mode completion --n-permutations 50 --device cuda:0 \
  --torch-dtype float16 --batch-size 16 \
  --input diversity-eval/data/with_metrics/conTest/con_test_200_with_hds_prompt_gen.csv \
          diversity-eval/data/with_metrics/conTest/con_test_200_with_hds_resp_gen.csv \
          diversity-eval/data/with_metrics/conTest/con_test_200_with_hds_story_gen.csv
# (the diversity-eval submodule must be checked out, or reachable via the main
#  repo working tree; the pre-existing qwen25_completion_v3 / qwen3_30b_a3b full
#  sidecars are gitignored artifacts under the main checkout's results/tevet/)

# analysis + tables/macros; refreshes the generated tables above
uv run python scripts/analyze_tevet_grader_invariance.py --update-findings
```
